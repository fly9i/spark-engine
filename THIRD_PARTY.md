# Third-party software and models

This repository contains only original code (MIT). The following are used at build or run time and are fetched or
installed separately; none of their source is stored here.

| Component | Use | License | How it is obtained |
| --- | --- | --- | --- |
| [exllamav3](https://github.com/turboderp-org/exllamav3) v1.4.9 | EXL3 GEMM / MGEMM, weight reconstruction and Hadamard kernels for the GLM path (`libexllamav3_ext.so`); the EXL3 weight format | MIT | `scripts/build-exllamav3.sh` clones the tag and builds only its CUDA parts (`scripts/exllamav3_min_setup.py`); release archives ship the compiled library with its license in `lib/LICENSE.exllamav3` |
| [PyTorch](https://pytorch.org) 2.13 (CUDA 13.0) | libtorch (tensors, CUDA streams and graphs, c10d/NCCL process groups, cuBLAS) | BSD-3-Clause | `pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu130` |
| [tch-rs](https://github.com/LaurentMazare/tch-rs) 0.20 (`tch`, `torch-sys`) | Rust bindings to libtorch | MIT / Apache-2.0 | crates.io; `torch-sys` 0.20.0 is fetched by `scripts/fetch-deps.sh` and patched for libtorch 2.13 (`patches/`) |
| [NCCL](https://github.com/NVIDIA/nccl) 2.29.7 header | `nccl.h` matching libtorch's build ABI | BSD-3-Clause | downloaded by `scripts/fetch-deps.sh`; the NCCL library itself comes with PyTorch |
| CUDA 13.0 toolkit, cuBLAS, cuBLASLt | compiler and runtime libraries | NVIDIA CUDA EULA | NVIDIA packages |
| rdma-core (`libibverbs`) | RDMA all-reduce over the ConnectX-7 ports | BSD-2-Clause / GPL-2.0 (dual) | distribution package |
| Rust crates (`serde_json`, `memmap2`, `half`, `sha2`, `rayon`, `cc`) | engine | MIT / Apache-2.0 | crates.io |
| Python packages (`jinja2`, `tokenizers`, `numpy`, `pillow`, `av`) | OpenAI-compatible front end, image/video decoding | BSD / Apache-2.0 / HPND / BSD | pip |
